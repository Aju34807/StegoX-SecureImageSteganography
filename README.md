# StegoX - Secure Image Steganography App

## Overview
**StegoX** is a secure image steganography application that enables users to encode and decode hidden messages within images using **AES encryption**. It is built using Python and modern libraries like **ttkbootstrap** for the graphical user interface (GUI) and **cryptography** for AES encryption. The application allows users to securely store messages within image files and later retrieve them.

---

## Features
- 🔐 **Message Encoding**: Embed a secret message within an image file.
- 🔍 **Message Decoding**: Retrieve the hidden message from an encoded image.
- 🛡️ **AES Encryption**: Encrypt and decrypt messages for enhanced security.
- 🖥️ **User-friendly GUI**: Built with ttkbootstrap for a modern and sleek interface.
